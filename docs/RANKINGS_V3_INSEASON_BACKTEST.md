# In-season ranking backtest

Generated by `npx tsx tools/backtest-inseason-ranking.ts`.

Four checkpoints per season. Everything up to a checkpoint is input, everything after it is truth, which is rest-of-season 5-category value built the same two-pass way as every other board in this repo. Players with fewer than 5 games at the checkpoint are excluded; a rest-of-season rank off three games is noise.

**Value above replacement alone cannot change an in-season ranking.** Subtracting a constant and multiplying by a constant leaves the order untouched, so it only does anything when multiplied by games that differ per player. That is why the candidates below are per-game value, value times expected remaining games, and value above replacement times expected remaining games, rather than the four in the spec.
